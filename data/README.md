# Dataset setup

The notebook expects a file named `Training_Dataset_v2.csv`.

The raw dataset is intentionally not included here because its original source and redistribution permissions should be confirmed first.

## What to do
1. Download or obtain `Training_Dataset_v2.csv` from the original course/project source or dataset provider.
2. Confirm you are allowed to use it for a portfolio project.
3. For Google Colab, upload it to your Google Drive `MyDrive` folder.
4. For local execution, place it in the same folder as `SupplyGuard_Backorder_Prediction.ipynb`.

Do not upload private, restricted, or course-provided data to a public repository unless you have permission.
